GNS3

For a basic topology design, we simulated a single PC on the earth side and the moon side, each connected through a switch and a router to allow for scalability in the future.

OpenvSwitch

Openvsitch is a open Source software that gets deployed onto actual switch. It has many protocols, such as NetFlow, sFlow, IPFIX, RSPAN, CLI, LACP, 802.1ag, and an easy API.

VyOS

For the router we are using VyOS to allow for complex routing, space laser delay, and simulated networking. It allows for ethernet switching, and easy configuration for vlan VPCs.

Research

This diagram shows how the Earth facility, space segment, and Moon base are connected. It separates the network into four different connection types, and uses different connection types depending on the distance, speed, reliability, and mobility needed. The project requirements specifically call for fiber as the backbone, Ethernet for internal connections, wireless for devices, and Free Space Laser for space communication.

This diagram shows the network topology for our project. We simulated a single pc on the earth side and the moon side, each connected through a switch and a router to allow for scalability in the future. There is a separate link IP to broadcast, and only need two addresses: 10.254.0.1 and 10.254.0.2 for the routers sending info. Networks are linked through OSPF so they work dynamically instead of defining explicit IP links.
